# L’Écrin des Senteurs by Manon - Catalogue interactif

## Test local
Dans ce dossier, lancez :

```bash
python -m http.server 8000
```

Puis ouvrez : http://localhost:8000

## Publication GitHub Pages
Déposez tous les fichiers de ce dossier dans un dépôt GitHub public, puis activez Pages sur la branche main, dossier root.
